## Requisitos

## Instalación
1. Clonar el repositorio (o descargar/abrir la carpeta en tu compu).
2. `python -m venv .venv` (para crear el entorno virtual).
3. Activar el entorno virtual:
   - En Windows (CMD/PowerShell): `.venv\Scripts\activate`
   - En Mac/Linux: `source .venv/bin/activate`
4. `pip install -r requirements.txt` (para instalar las dependencias).

## Ejecución
`python app.py` (o el nombre del archivo principal con el que arranca tu programa).
